# Morangópolis — Mundo das Makes

Site de vendas da **Morangópolis** com estética Strawberry Kawaii / Coleção Doces Sonhos.

## Como abrir

Abra o arquivo `index.html` no navegador ou use um servidor local:

```bash
cd C:\Users\JUNIOR\Projects\morangopolis
npx serve .
```

## Funcionalidades

- **Produtos** por categoria: Olhos, Lábios e Pele
- **Acessórios** exclusivos (cintos, joias, tênis, necessaire)
- **Carrinho** com quantidade e total
- **Cupom de desconto** (teste: `MORANGO10`, `DOCES20`, `FRETEGRATIS`)
- **Termos de uso**, **políticas de entrega** e **privacidade** no rodapé

## Estrutura

- `index.html` — página principal
- `styles.css` — visual rosa, preto, vermelho morango e dourado
- `app.js` — produtos, carrinho e cupons
- `assets/` — imagens
